# Cursor Commands

This directory contains focused command files extracted from `.cursorrules` for easier reference and maintenance.

## Available Commands

### Code Standards
- **[code-standards.md](./code-standards.md)** - General code standards, best practices, and changelog requirements

### Documentation
- **[documentation.md](./documentation.md)** - Documentation requirements for JavaScript and PHP functions

### Project Structure
- **[project-structure.md](./project-structure.md)** - Project structure preferences for Nuxt.js and WordPress plugins

### Styling
- **[styling.md](./styling.md)** - Tailwind CSS styling guidelines and responsive design patterns

### Tech Stack
- **[tech-stack.md](./tech-stack.md)** - Technology stack preferences (Vue.js, Nuxt.js, PHP, Node.js)

### UI Design
- **[ui-design.md](./ui-design.md)** - Modern Dark Minimalist design system guidelines

### Vue.js
- **[vue-guidelines.md](./vue-guidelines.md)** - Vue.js 3 Composition API guidelines and component structure
- **[component-size.md](./component-size.md)** - Guidelines for breaking up large Vue components into smaller, maintainable pieces
- **[shadcn-vue-components.md](./shadcn-vue-components.md)** - Guidelines for using shadcn-vue components from `app/src/components/ui`

### Utilities
- **[deslop.md](./deslop.md)** - Remove AI-generated code slop from diffs

## Usage

These commands can be referenced individually when working on specific aspects of the codebase. The main `.cursorrules` file contains all rules consolidated, while these files provide focused, topic-specific guidance.
