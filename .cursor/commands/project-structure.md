# Project Structure Preferences

## Nuxt.js Projects

- Follow Nuxt 3 directory structure
- Use `pages/` for routing
- Leverage `composables/` for reusable logic
- Store API routes in `server/api/`
- Utilize `middleware/` for route protection

## Directory Organization

- **Pages**: Use `pages/` directory for routing (Nuxt.js)
- **Composables**: Store reusable logic in `composables/`
- **API Routes**: Store in `server/api/` (Nuxt.js)
- **Middleware**: Use `middleware/` for route protection

## WordPress Plugins

- Follow WordPress plugin structure conventions
- Separate admin and frontend code appropriately
- Use proper namespacing for PHP classes
