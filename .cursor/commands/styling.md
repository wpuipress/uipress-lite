# Styling Guidelines

## Tailwind CSS Usage

- Use Tailwind utility classes
- Always use the colour 'slate-x' for neutral backgrounds and borders
- Design everything with dark mode supporting classes
- Prefer responsive design patterns
- Maintain consistent spacing using Tailwind's scale
- Use semantic color names when defining custom colors
- Follow mobile-first responsive approach

## Color Usage

- Use 'slate-x' for neutral backgrounds and borders
- Design with dark mode in mind
- Use semantic color names for custom colors

## Responsive Design

- Mobile-first approach
- Use Tailwind's responsive breakpoints
- Maintain consistent spacing using Tailwind's scale
