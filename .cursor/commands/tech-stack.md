# Tech Stack & Preferences

## Frontend

- **Vue.js 3** with Composition API
- Always use `<script setup>` syntax
- **Nuxt.js** for full-stack applications (except WordPress plugins)
- **Tailwind CSS** for styling

## Backend

- **Node.js** for server-side JavaScript
- **PHP** for WordPress plugins and legacy systems

## Framework Selection

- Use **Nuxt.js** for full-stack applications
- Use **Vue.js 3** directly for WordPress plugins
- Use **PHP** for WordPress backend functionality
