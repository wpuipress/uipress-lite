# Dashboard Reference

This section provides an overview of the dashboard in Polar, including how to log in and access various settings related to your organization.

## Overview

The Polar dashboard is designed to facilitate the management of your SaaS and digital products. Users can log in using various authentication methods and access different settings, including webhooks.

## Logging In

To access the Polar dashboard, you can log in using one of the following methods:

### Authentication Options

- **GitHub**: 
  [Continue with GitHub](https://api.polar.sh/v1/integrations/github/login/authorize?return_to=%2Fdashboard%2FORG_SLUG%2Fsettings)
  
- **Google**: 
  [Continue with Google](https://api.polar.sh/v1/integrations/google/login/authorize?return_to=%2Fdashboard%2FORG_SLUG%2Fsettings)
  
- **Apple**: 
  [Continue with Apple](https://api.polar.sh/v1/integrations/apple/authorize?return_to=%2Fdashboard%2FORG_SLUG%2Fsettings)

- **Or**: Login directly.

By using Polar, you agree to our [Terms of Service](https://polar.sh/legal/terms) and [Privacy Policy](https://polar.sh/legal/privacy).

## Accessing Webhooks

To manage webhooks, navigate to the following URL:

- **Webhooks Settings**: 
  [Webhooks Settings](https://polar.sh/dashboard/ORG_SLUG/settings/webhooks)

### Authentication Options for Webhooks

Similar to the main dashboard, you can log in using:

- **GitHub**:
